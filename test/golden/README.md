# Golden wire vectors

`abci.golden` is generated by CometBFT's *own* Go encoder, so the OCaml codec is
checked against the real implementation rather than only against itself. Each
line is one of:

    varint <decimal>  <hex>     -- Go's binary.PutUvarint
    frame  <label>    <hex>     -- abci/types.WriteMessage of a Request,
                                   i.e. exactly what a node puts on the socket

Regenerate (needs Go, and network access the first time):

    cd test/golden && go run . > abci.golden

Pinned to CometBFT **v0.40.0** in `go.mod`, matching the protos vendored in
`proto/`. Pin it explicitly: `go mod tidy` will happily "upgrade" to v1.0.1,
which is the abandoned v1.x branch and speaks a different, wire-incompatible
ABCI dialect.
